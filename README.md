# Job Hunt CLI Tracker

A lightweight, terminal-based application built with Python to track job applications, interview stages, and assessment tests.

## Features (Planned)
- Log new job applications (Company, Role, Date)
- Update application statuses (e.g., CBT Assessment, HR Interview, Hired, Rejected)
- View a summary of active applications

This project is intended as a personal utility tool and is open-sourced under the MIT License.
